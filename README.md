# second_semester — Consolidated Coursework

This branch gathers the real coursework that was scattered across separate
branches in this repository, organized into one place with clean, descriptive
filenames. The original branches are left untouched.

## Contents

### `lab1/` (from branch `lab1`)
- `sort_string_letters.cpp` — reads a line of input, strips spaces and
  punctuation, lowercases it, and sorts the remaining letters alphabetically.
- `fibonacci_triangle.cpp` — builds a triangular array of Fibonacci-style
  numbers using dynamically allocated memory (`new[]` / `delete[]`).

### `lab2/` (from branch `lab2`)
- `student_grade_analyzer.cpp` — collects student names/grades (demo, random,
  or user input), computes averages, and produces an A–F grade distribution.

### `moon-10-mission/` (from branch `moon-10-mission`)
- `luna10_orbit_anomalies.c` — computes the true, eccentric, and mean
  anomalies over one orbital period for the Luna 10 mission and writes the
  results to a gnuplot data file.
- `REPORT.pdf` — accompanying mission report.

### `orbital-velocity-vs-altitude/` (from branch `Задание2.-График-зависимости-скоростиконца-геоцентрического-радиус-вектораот-высоты-спутника-при-постоянном-наклонении`)
- `orbital_velocity_vs_altitude.c` — computes circular orbital speed and the
  velocity of the end of the geocentric radius vector at a fixed (45°)
  inclination, across a range of satellite altitudes, and plots both with
  gnuplot.
- `orbital_velocity_vs_altitude_report.pdf` — accompanying report ("Задание 2.
  График зависимости скорости конца геоцентрического радиус-вектора от высоты
  спутника при постоянном наклонении").
